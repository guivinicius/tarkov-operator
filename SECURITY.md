# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public issue.**
2. Email the maintainer or use [GitHub Security Advisories](https://github.com/guivinicius/tarkov-operator/security/advisories/new).
3. Include a description of the vulnerability, steps to reproduce, and potential impact.

We aim to respond within 48 hours and release a fix within 7 days for critical issues.

## Scope

- API key handling and storage
- IPC security between main and renderer processes
- Network request handling
- Local command execution
